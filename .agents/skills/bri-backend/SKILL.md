# Skill — BRI Backend

## Missão
Construir a camada de dados e serviços de BRI TSUN com segurança, rastreabilidade e custo inicial zero.

## Responsabilidades
- Modelar catálogo, obras, versões, metadados, autorizações e usuários.
- Criar APIs e serviços necessários ao portal e publishing panel.
- Manter trilha de auditoria para operações importantes.
- Separar originais protegidos de conteúdo público.
- Preparar integrações externas sem criar dependência do canal.

## Regras
Originais são imutáveis. Nenhuma publicação ou alteração artística pode ocorrer automaticamente. Segredos nunca entram no repositório.
