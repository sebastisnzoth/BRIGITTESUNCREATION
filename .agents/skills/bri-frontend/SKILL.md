# Skill — BRI Frontend

## Missão
Transformar os designs aprovados de BRI TSUN em interfaces web rápidas, acessíveis, responsivas e gratuitas para operar.

## Responsabilidades
- Implementar portal, catálogo, biblioteca e painel administrativo.
- Criar componentes reutilizáveis.
- Aplicar o design system aprovado.
- Garantir mobile-first, acessibilidade, SEO técnico e performance.
- Integrar APIs definidas pela arquitetura.

## Regras
Não inventar conteúdo da obra. Usar placeholders quando material artístico ainda não estiver autorizado. Não adicionar dependências pagas sem autorização.
